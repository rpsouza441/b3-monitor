## Six challenged assumptions

1. A one-session freshness measurement is permanent: rejected; enforce per-use source-age policies and retain uncertain timestamps/stale flags.
2. RAW and adjusted histories merge safely: rejected; separate series, selected lineage and action compatibility. Equal current values do not prove compatible historical basis.
3. Portfolio valuation/performance is a trading signal: rejected in proposed v1; user must explicitly approve context-only scope. A manual target is not generated by Graham/PVP/weights.
4. Scraper stores OHLCV or provides harmless cache reads: contradicted by audit; snapshot/raw GET is not a safe cachedOnly integration.
5. WAHA HTTP acceptance proves delivery: rejected; submission/delivery dimensions independent, uncertain send cannot blindly retry.
6. Every implemented financial formula is READY: rejected; producer statuses/coverage/use are preserved separately from local assurance and export readiness.
